# 开发日志使用说明

## 📖 什么是开发日志？

`DEVELOPMENT_LOG.md` 是项目的日常开发记录文档，用于：

- 记录每天的开发内容
- 追踪代码变更历史
- 帮助团队成员了解项目进度
- 避免重复开发和冲突

## 📍 文档位置

```
D:\AICheck\DEVELOPMENT_LOG.md
```

## ✍️ 何时记录？

每次完成开发任务后，立即记录：

- ✅ 新增功能模块
- ✅ 修改现有代码
- ✅ 修复 Bug
- ✅ 更新文档
- ✅ 配置变更

## 📝 记录格式

```markdown
### YYYY-MM-DD - [你的名字]

#### 类型
- ✨ 新增 (Feature)
- 🐛 修复 (Bugfix)
- 📝 文档 (Documentation)
- ♻️ 重构 (Refactoring)
- ⚡ 性能 (Performance)
- 🔧 配置 (Configuration)
- 🧪 测试 (Test)

#### 变更内容
- 模块/文件：具体变更描述

#### 备注
- 可选的补充说明
```

## 📋 完整示例

```markdown
### 2024-05-08 - [张三]

#### 类型
- ✨ 新增
- 🧪 测试

#### 变更内容
- `detectors/forgery/ai_detector.py`: 实现 AI 生成图片检测器
  - 使用频域分析算法
  - 支持批量处理
- `tests/test_forgery.py`: 添加对应单元测试
  - 测试正常图片检测
  - 测试 AI 生成图片检测

#### 备注
- 准确率约 85%，后续可优化
- 需要 GPU 支持以提高性能
```

## 🤖 AI 助手规则

AI 助手在参与项目开发时必须：

1. **开始任务前**: 读取 `DEVELOPMENT_LOG.md`
2. **理解上下文**: 了解最近的开发内容
3. **完成后提醒**: 提醒用户更新日志

## ✅ 开发流程

```
开始任务
   │
   ▼
读取 DEVELOPMENT_LOG.md ← 必须步骤
   │
   ▼
执行开发任务
   │
   ▼
测试验证
   │
   ▼
更新 DEVELOPMENT_LOG.md ← 必须步骤
   │
   ▼
提交代码
```

## 🔗 相关文档

| 文档 | 用途 | 更新频率 |
|------|------|----------|
| `DEVELOPMENT_LOG.md` | 日常开发记录 | 每次开发后 |
| `CHANGELOG.md` | 版本变更历史 | 每个版本发布 |
| `docs/guides/development.md` | 开发规范 | 规范变更时 |

## 💡 最佳实践

1. **及时记录**: 完成开发后立即记录，不要拖延
2. **详细描述**: 写清楚变更内容和原因
3. **标注类型**: 使用 Emoji 标记变更类型
4. **关联文件**: 列出修改的文件路径
5. **补充说明**: 备注中记录注意事项或待办事项

## ⚠️ 注意事项

- 不要删除历史记录
- 按时间顺序添加，最新的在最前面
- 保持格式统一
- 重大变更同步更新 `CHANGELOG.md`

**开发日志是团队协作的重要工具，请认真填写每一条记录！**
