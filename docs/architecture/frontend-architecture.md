# 前端功能模块架构

## 前端技术栈

- **框架**: PyQt6
- **架构模式**: MVC (Model-View-Controller)
- **样式**: QSS (Qt Style Sheets)
- **多线程**: QThread + 信号槽机制

## 信号槽设计

```python
# 主要信号定义

# 检测面板 → 主窗口
detection_started = pyqtSignal()
detection_finished = pyqtSignal(list)  # 结果列表
detection_progress = pyqtSignal(int, int)  # 当前，总数

# 后台线程 → UI 线程
worker_progress = pyqtSignal(int, int, str)  # 当前，总数，消息
worker_finished = pyqtSignal(bool)  # 成功/失败
worker_error = pyqtSignal(str)  # 错误信息

# 数据管理 → 其他模块
data_updated = pyqtSignal()  # 数据更新通知
model_loaded = pyqtSignal(str)  # 模型加载通知

# 主窗口 → 状态栏
status_changed = pyqtSignal(str)  # 状态文本
progress_changed = pyqtSignal(int)  # 进度值
```

```
┌─────────────────────────────────────────────────────────────┐
│                      界面状态流转                            │
└─────────────────────────────────────────────────────────────┘

空闲状态
   │
   ├─ 点击"开始" → 检测中状态
   │                  │
   │                  ├─ 点击"暂停" → 暂停状态
   │                  │                │
   │                  │                └─ 点击"恢复" → 检测中状态
   │                  │
   │                  ├─ 点击"停止" → 停止状态 → 空闲状态
   │                  │
   │                  └─ 检测完成 → 完成状态 → 空闲状态
   │
   └─ 点击"设置" → 设置状态 → 空闲状态
```
