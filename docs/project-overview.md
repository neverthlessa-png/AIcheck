# 项目概述

## 项目简介

**AI Check** 是一个本地运行的图片AI检查桌面工具，旨在替代人工进行图片内容的自动化检测。该项目支持多种检测功能，包括图片伪造检测、重复图片检测、文档内容检测等，适用于需要大规模图片审核的场景。

### 核心功能

| 功能模块 | 说明 | 应用场景 |
|---------|------|---------|
| 伪造检测 | 检测PS编辑、AI生成、拼接、复制粘贴等篡改 | 图片真实性验证 |
| 重复检测 | 精确重复和相似图片检测 | 图库去重、版权检查 |
| 文档检测 | 合同、票据等文档的篡改检测 | 文档审核 |
| 内容检测 | OCR文字提取、敏感内容识别 | 内容合规检查 |

### 技术特点

- **本地运行**：所有检测在本地执行，数据不外传，保障隐私安全
- **可扩展**：插件化的检测器架构，支持自定义检测器
- **高性能**：支持GPU加速和并行处理，适合大规模图库
- **跨平台**：支持Windows、Linux、macOS

## 项目背景

### 业务需求

在企业的日常运营中，存在大量需要人工审核的图片内容，例如：

1. **合同/票据审核**：验证文档是否被篡改
2. **图库管理**：检测重复或相似图片，优化存储
3. **内容审核**：检测违规内容、AI生成图片
4. **证件验证**：验证身份证、护照等证件真伪

传统人工审核存在效率低、成本高、标准不统一等问题，本项目旨在通过AI技术实现自动化检测。

### 目标用户

- 企业审核部门
- 图片库管理员
- 法务/合规部门
- 内容审核团队

## 技术选型

### 为什么选择Python？

- **AI生态丰富**：PyTorch、TensorFlow、ONNX Runtime等成熟框架
- **开发效率高**：快速迭代和原型验证
- **社区支持好**：大量开源模型和工具

### 为什么选择PyQt6？

- **成熟稳定**：Qt是最成熟的跨平台GUI框架之一
- **打包方便**：PyInstaller支持打包为独立exe
- **性能好**：原生控件，响应速度快

### 为什么选择ONNX Runtime？

- **跨平台**：支持CPU、CUDA、TensorRT等多种后端
- **模型通用**：支持从PyTorch、TensorFlow转换的模型
- **性能优化**：内置多种优化策略

### 为什么选择SQLite？

- **轻量级**：无需独立数据库服务
- **本地存储**：数据不外传，符合隐私要求
- **性能足够**：对于本地应用，SQLite性能完全满足

## 项目范围

### 包含的功能

- 图片伪造检测（PS编辑、AI生成、拼接、复制粘贴）
- 图片重复检测（精确重复、相似图片）
- 文档检测（OCR、模板匹配）
- 大规模批量处理
- 检测结果持久化存储
- 报告导出（Excel、CSV）

### 不包含的功能

- 云端API调用（完全本地运行）
- 实时视频流检测
- 移动端应用
- 多用户权限管理
